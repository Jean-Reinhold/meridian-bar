### Added

- All-accounts menu bar label: one colored segment per Meridian profile,
  7d Fable window as the primary number, worst-window color, active
  profile underlined (F1).
- Per-account dropdown cards with per-window usage bars, reset countdowns,
  profile switching, health footer, and offline banner (F4–F7).
- 60 s polling with immediate refresh on menu open and wake; two-miss
  hysteresis before declaring Meridian offline (F2–F3).
- SwiftPM package, Makefile bundle assembly, unit tests for all pure
  logic against redacted live-shape fixtures.
